SGLang inference engineering learning track

This folder contains SGLang-specific architecture, implementation notes, mind maps, and source exercises. Generic LLM/multimodal/multi-model material is kept once in the sibling vLLM learning library.

#Reading path

Start by naming the serving problem and its success criterion in the shared workload card. The PDF reading bridge explains the problem -> example -> mechanism -> source -> evidence structure. This keeps a source tour connected to the latency, memory, or correctness problem it is meant to explain.

Prefer learning from code? Start with the shared 12-lesson code-first course. SGLang is the primary reading path and vLLM is the comparison. Every lesson includes source symbols, a worked example, exercises, an answer key, and a design contrast. Keep the side-by-side design reference open while tracing the implementations.

For the first ten minutes, use the one-request architecture story: read a three-token prompt, choose an output, then reuse the saved context. The complete subsystem and source maps are optional expandable references.

#Evidence boundary

Inspected 2026-10-13, commit 5eda6b7e674458c0c01f93801012b6ff6c15064e. The companion vLLM checkout was 2f18d13cf083c4db8a6d140d8475fbfcffc084fd.

The focus is the Python SGLang Runtime (SRT) serving path: request processing, scheduling, memory, model execution, multimodal integration, and distributed serving. Other paths, including Rust serving and diffusion generation, are related systems, not assumed to execute this same loop.

Source links are local and revision-specific. The architecture deliberately notes ongoing alternatives such as unified caches rather than presenting the classic radix implementation as the only production path.

These are original study notes, not benchmark claims. GPU labs were not run while preparing them. Read on Windows; execute GPU experiments only in an appropriately prepared supported Linux environment. Follow test guidance and the project installation documentation before running commands.

Cross-repository links assume sglang and vllm remain sibling folders. Mermaid-capable Markdown preview renders the diagrams; prose and tables provide the same navigation if preview is unavailable.

A visual HTML edition of this track is in html/index.html. It shares assets, search, and calculators with the vLLM-side HTML edition and is regenerated by the shared HTML generator.

Completion standard

be able to trace one request's IDs, KV ownership, forward metadata, sampled tokens, and cleanup through the actual selected path, then explain a performance change with a reproducible measurement.
